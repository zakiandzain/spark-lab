# Spark Lab

Teach Zaki (16) to build apps with Grok.

This GitHub repo is the shared save file between **this Grok chat** and **Grokbot**. Paste the URL into Grokbot and say: *read GROKBOT.md and continue.*

**Repo:** [github.com/zakiandzain/spark-lab](https://github.com/zakiandzain/spark-lab)

## What this is

Spark Lab is an eight-lesson course (~20 minutes each) that teaches vibe coding, enough code to steer, and GitHub. A live Grok mentor sits in the corner of the app.

| # | Lesson | Point |
|---|---|---|
| 1 | Hello Grok | Brief a teammate, not a vending machine |
| 2 | Vibe coding | Describe the product. Iterate. Read what came back |
| 3 | How apps work | Interface, state, events |
| 4 | Prompt like a builder | Constraints and examples |
| 5 | Code without fear | Variables, functions, components |
| 6 | When it breaks | Paste the error, not "it doesn't work" |
| 7 | GitHub for real | Repo, commit, branch, pull request |
| 8 | Ship something | A real brief he can paste into Grok today |

Examples swap to his interests (games, music, sports, film, art, social, tools, robots).
